VIDEO PROFILE
- Canvas: 1920x1080 (16:9).
- Output for reliable streaming: 1280x720, 30 FPS; use 1920x1080 only when the PC and upload connection can sustain it.
- Encoder: hardware encoder if available and stable; otherwise x264 Veryfast. If encoding lag occurs, use Superfast or reduce output resolution.
- Rate control: CBR; keyframe interval: 2 seconds.

- Audio: AAC 128 Kbps, 48 kHz.
- Recording: MKV; remux to MP4 only after checking the MKV.

AUDIO
Microphone: light noise suppression → gentle expander/noise gate → moderate compressor → limiter (ceiling near -1 dB).
Camera: correct lighting and white balance first; apply mild correction only if needed.
Listen to a test recording with headphones. Avoid aggressive noise suppression that damages speech.

NETWORK & PERFORMANCE
- Use wired Ethernet where possible; otherwise keep the streaming device close to the router and minimise other network traffic.
- Run a private/unlisted test before each service.
- OBS View > Stats: watch dropped frames (network), rendering lag and encoding lag.
- If network drops rise, reduce bitrate. If encoding/rendering lag rises, reduce output resolution/FPS or encoder load.
- A stable 720p stream is better than a repeatedly interrupted 1080p stream.

IMPORTANT
Preview every scene and check safe margins on the actual output. Confirm spelling, programme times, Bible translation, media permissions and approved public details before going live.
